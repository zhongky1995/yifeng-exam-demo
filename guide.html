本轮四处调整

  1. 每个班次考场安排监考与录制各一人，示例为甲、乙。两岗不能同人，同一时段不能跨考场兼岗。修改先保存，再核对岗位及单科评分分工，最后检查开放。
  2. 教务主看板按老师及其科目显示有效已评/应评、完成率、平均每份评分耗时、本人均分和各分数段人数占比。可筛选、展开某位老师明细、点击分段，按科目与老师导出Excel三表。考试录制统计放在独立辅助区。
  3. 评分页只按本人本科分数段和最低/最高分筛选，移除匿名任务号搜索。匿名标识保留用于定位视频；视频优先、纵向最近15份本人评分、紧凑右下打分、当前批回改、0分有效和漏评禁提交继续保留。
  4. 三科统一显示准备文字并语音播报科目及“请考生准备好”，接3、2、1、开始；约7秒提示结束后才开录，不占120/60/120秒答题时间。保存成功后自动接续；语音失败停在准备并可重播，老师可暂停后重新播放完整提示。只有当前录制工作台播音，配套投屏只同步画面。

怎样理解评分耗时

本地体验从进入评分页累计看片、看题、思考及当前批回改的有效时间，剔除页面隐藏、保存等待及暂停看片后60秒无操作；平均值只用有记录答卷计算，未记录不补0。虚构样例、本地体验计时和未记录分别标注。正式采集口径仍待确认。

完整业务路径

建立考点班次 → Excel导入校验 → 分配考场/时间/排次 → 选完整套卷 → 双岗与评分分工核对 → 检查开放 → 学生看本人安排并现场扫码 → 一次抽三科、统一15分钟备考 → 监考核验交接 → 录制员启动三科 → 原片技术检查与系统上传 → 监考核验放行 → 教务核验材料、开放本科 → 老师匿名评卷并提交本批 → 教务内部核查与统计。

Excel可下载模板，读取.xlsx/.xls/.csv，核对字段、逐行修正/明确排除、错误导出、预览确认；已有记录跳过，身份冲突拦截。安排可按班次和考场配置容量、时间、排次，未分配或有冲突时不能确认开放。文件仅当前浏览器解析。

考生始终不能看成绩，但可回看教务已开放、逐科已核验的本人视频。录像开放演示仍按整场结束统一处理；逐班次独立开放、下载分享与保存期限后续细化。固定Pad备考位及宿舍本人手机模拟考保留后续候选。

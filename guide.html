从名单到现场接收的完整交接

修改筛选条件后须先应用，选择和分配暂时停用，防止使用旧范围。分配部分考生后可直接继续安排剩余未分配者。手机选择考生使用更大的可点区域。首次待交接和上一位已放行分别提示；设备复核显示检查项进度，漏项提示后保留已勾选内容，补齐后返回同一考生接收。

核验接收与考生分配

录制员按核验考号、复核机位设备、确认核验并接收操作；设备检查未完成时不能接收，检查后返回当前考生。教务先筛选并全选考生（含其他分页），再选择目标班次、考场和自动/指定起始排次，预览逐人去向，确认分配草稿，最后确认全部安排。自动按名单顺序接续已有排次，全部考场依次填满；容量不足或冲突整次不修改。

整体动线与一致性修正

  1. 每个班次考场安排监考与录制各一人，示例为甲、乙。两岗不能同人，同一时段不能跨考场兼岗。岗位任务按本人班次和考场呈现，设备、队列和当前考生分别维护。关键配置一经修改即撤销原核对，先保存、再核对，最后检查开放。
  2. 教务主看板按老师及其科目显示有效已评/应评、完成率、平均每份评分耗时、本人均分和各分数段人数占比。可筛选、展开某位老师明细、点击分段，按科目与老师导出Excel三表。考试录制统计放在独立辅助区。
  3. 评分页只按本人本科分数段和最低/最高分筛选，移除匿名任务号搜索。匿名标识保留用于定位视频；视频优先、纵向最近15份本人评分、紧凑右下打分、当前批回改、0分有效和漏评禁提交继续保留。正式缺考按用户确认单列保留在名单与报表，不计应评、不生成分数；普通缺视频仍须处理。
  4. 三科统一显示准备文字并语音播报科目及“请考生准备好”，接3、2、1、开始；约7秒提示结束后才开录，不占120/60/120秒答题时间。保存成功后自动接续；语音失败停在准备并可重播，老师可暂停后重新播放完整提示。只有当前录制工作台播音，配套投屏只同步画面。

怎样理解评分耗时

本地体验从进入评分页累计看片、看题、思考及当前批回改的有效时间，剔除页面隐藏、保存等待及暂停看片后60秒无操作；评分和耗时绑定当前有效视频版本，替换后新版本重新计时；平均值只用有记录答卷计算，未记录不补0。虚构样例、本地体验计时和未记录分别标注。正式采集口径仍待确认。

当前工作与历史记录

录制工作台和投屏跟随本考场当前考生；三科原片检查、原文件和异常详情固定指定考生/科目/版本。投屏在配套新页打开，录制进行中先暂停接续再离开，避免中断准备语音。补录沿同一考试流程，只处理未完成科目；材料换版后教务核验并重开本科，再按原因退回原评卷批给原老师重评。

完整业务路径

建立考点班次 → Excel导入校验 → 分配考场/时间/排次 → 选完整套卷 → 双岗与评分分工核对 → 检查开放 → 学生看本人安排并现场扫码 → 一次抽三科、统一15分钟备考 → 监考核验交接 → 录制员启动三科 → 原片技术检查与系统上传 → 监考核验放行 → 教务核验材料、开放本科 → 老师匿名评卷并提交本批 → 教务内部核查与统计。
